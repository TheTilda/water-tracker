# Трекер воды

Android-приложение: Kotlin, Jetpack Compose (Material 3), Room, WorkManager. minSdk 26.

- **Сегодня** — круговой прогресс, кнопки «+ Стакан» (порция из настроек), «+ Бутылка» (500 мл), «Другой объём», список порций и отмена последней. После двух дневных норм всплывает шуточное предупреждение о «передозировке» воды.
- **История** — все дни от первой записи до сегодня (дни без записей — с нулём), отметка о выполнении нормы.
- **Настройки** — дневная норма (пресеты 1500/2000/2500), порция стакана, напоминания с интервалом. Применяются только по кнопке «Сохранить».

Сборка: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом).
